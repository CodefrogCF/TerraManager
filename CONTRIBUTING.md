# Contributing to TerraManager

Bug reports, reproducible test results, feature discussions and suggested
documentation corrections are welcome through
[GitHub Issues](https://github.com/CodefrogCF/TerraManager/issues).

## Code and content contributions

TerraManager is distributed under `GPL-3.0-or-later`. The maintainer also wants
to preserve the option of offering separate commercial licence terms in the
future. Copyright ownership and contribution terms must therefore be clear.

Until a separate contributor agreement is published, please do not submit
unsolicited pull requests containing substantial source code, translations,
artwork or documentation. Open an Issue first and agree on the contribution
scope and terms with the maintainer. This avoids accepting work that cannot
later be relicensed consistently.

Any accepted contribution must be original work or material the contributor is
authorized to provide. It must not introduce secrets, real user data, copied
proprietary code or incompatible third-party content.

## Development checks

For an agreed change, follow [docs/development.md](docs/development.md) and the
[toolchain baseline](docs/toolchain-baseline.md), then run the relevant
formatting, analysis and test checks. Platform-dependent changes also require
manual validation on their affected target. Every push and pull request is
checked by the public Quality Gates workflow.
