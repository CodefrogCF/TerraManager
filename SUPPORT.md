# TerraManager Support

TerraManager is maintained as an open-source project. Community support is
provided on a best-effort basis without a guaranteed response or resolution
time.

## Supported platforms

The currently validated platforms are Android and Web. iOS, macOS, Linux and
Windows projects may be present in the repository, but they are not currently
validated or supported release targets.

## Report a problem

Use [GitHub Issues](https://github.com/CodefrogCF/TerraManager/issues) and check
for an existing report first. A useful report includes:

- TerraManager version and build number
- platform, operating-system version and, for Web, browser version
- clear reproduction steps
- expected and actual behaviour
- the smallest useful log excerpt or screenshot
- whether the problem still occurs after restarting the application

Remove personal or sensitive content before posting. Never publish real
`.tmbackup` files, Box or Animal pictures, private notes, passwords, keystores,
signing credentials or signing-key backups.

## Feature requests

Feature requests are welcome as GitHub Issues. Explain the use case and desired
outcome before proposing a particular implementation. New work is prioritized
through milestones and is not guaranteed to be accepted.

## Security and privacy reports

Do not publish exploit details, private records or a real backup in a public
issue. Follow [SECURITY.md](SECURITY.md) for responsible reporting. For a
privacy question that does not expose private data, use a normal GitHub Issue
and refer to [PRIVACY.md](PRIVACY.md).

## Installation and updates

Installation, artifact verification, Android update-signature requirements and
Web deployment notes are documented in
[docs/installation-and-updates.md](docs/installation-and-updates.md).
