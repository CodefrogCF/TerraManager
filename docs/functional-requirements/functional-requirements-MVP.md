## Functional Requirements – MVP

### Boxes

- create a new box
- edit box data
- delete a box
- identify a box by QR code
- view box overview

### Animals

- assign an animal to a box
- view animal overview
- edit animal data
- add photo
- add notes
- save preferred temperature and humidity values

### Feeding

- add a feeding event
- view feeding history
- view latest feeding

### QR

- generate unique QR ID for a box
- assign a QR ID to a box
- export QR code as image
- scan QR code
